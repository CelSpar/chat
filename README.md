Realtime Chat App: SPQRord/chat
This is a simple Realtime Chat application built with HTML, CSS, and JavaScript, utilizing Supabase for realtime database interactions. Users can join a chat by entering their name and send/receive messages in real-time. The app also supports message reactions, typing indicators, and link detection.
Features
Realtime Messaging: Messages are sent and received instantly without refreshing the page.
Message Reactions: Users can react to messages with emojis (✅, ❌, 😂) in real-time. Each user can only react once per emoji per message.
Typing Indicator: Displays when a user is typing a message.
Anti-Spam Cooldown: Limits the rate at which users can send messages.
Auto Link Detection: Automatically detects and links URLs in messages.
Responsive Design: Fully functional on both desktop and mobile.
Technologies Used
HTML5 & CSS3 for the frontend.
Supabase for the realtime backend, handling message storage and syncing.
JavaScript for managing user interactions, sending/receiving messages, and handling reactions.
